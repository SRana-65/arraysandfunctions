
# JavaScript - Arrays and Functions

## About the Project

This project is based on JavaScript Arrays and Functions.

It performs different operations on an array of numbers entered by the user.

## Features

- Find the maximum number in an array.
- Calculate the sum of all elements.
- Count the odd numbers.
- Accept user input.
- Display results in the browser.
- Display results in the browser console.
- Validate user input.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the project in a browser.
2. Enter numbers separated by commas.
3. Click the Calculate Results button.
4. View the results on the webpage.
5. Open the browser console to see the results there too.

## Sample Input

4, 8, 2, 11, 6, 7, 10

## Expected Output

- Maximum Number: 11
- Sum of All Elements: 48
- Count of Odd Numbers: 2

## Project Files

- index.html - Structure of the webpage.
- style.css - Styling of the webpage.
- script.js - Array operations and calculations.
